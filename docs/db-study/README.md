# 数据库底层原理学习文档 · 总览

> 这是一套**通用**的数据库原理学习文档：面向会写 SQL、日常用 ORM，但没有系统学过数据库内部原理的开发者，目标是把「会用数据库」升级为「懂原理、能调优、能排查故障」的高级开发者。
> 每篇都遵循同一条主线：**先建立直觉（类比 + 示意图），再拆机制细节，最后落到开发者日常该做什么、不该做什么。**
>
> 注意：这套文档讲的是通用原理（以 MySQL 8.0 / PostgreSQL 16 为主要参照）。Tillgate 项目自身的表结构与迁移文档在 [../db/](../db/README.md)，两套互补：这里是「为什么数据库这样工作」，那里是「这个项目的库为什么这样设计」。

## 怎么用这套文档

1. **对照动手**：本地用 Docker 起一个 PostgreSQL 和一个 MySQL，每篇的 SQL 示例都跑一遍。原理只有配上观察才能内化。
2. **抓住每篇的「开发者清单」和「常见误区」**：这两节是原理到日常代码的翻译层，建议读完正文后隔天再回顾一次。
3. **用「自测题」检验**：答不上来自测题，说明该回去重读对应小节，而不是继续往后翻。
4. **结合项目**：读完 01/02/17 后，可以打开 [../db/](../db/README.md) 看 Tillgate 的真实表设计，检验自己能否解释每一处设计的原因。
5. **版本意识**：文中版本相关的行为与默认值以 MySQL 8.0、PostgreSQL 16 为准（会显式标注）。升级或使用其他版本时，先查对应版本文档确认。

- SQL 示例标注数据库；不确定的参数/行为不写，宁可少写不写错。
