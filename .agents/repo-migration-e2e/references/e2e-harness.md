# e2e 装置建造与旧 e2e 迁移细则

## 装置组成（kit）

一个共享装置模块 + 按职责拆分的辅助模块（如替身服务器独立成文件）。组成：

1. **隔离世界**
   - 每测试文件独占隔离数据区（独立 schema / 独立库 / 独立前缀）；
   - 建表方式 = 回放真实迁移链（DDL 单一真源，不复制 SQL）；
   - 对「跨链引用的祖先表不在回放集」类错误按数据库错误码白名单容忍，其余照常失败；
   - 库名/schema 名带 pid+时间戳防碰撞；结束整体销毁（drop cascade 类动作）；
   - 连接串层面锁定数据区（如 search_path），应用零感知。
2. **脚本化外部依赖替身**
   - 本地起真实网络 server（协议与真实对端兼容），行为可编程；
   - 脚本枚举覆盖全部向量：正常应答、错误应答、慢响应、慢流、挂住不结束、
     超大/畸形数据、鉴权失败；并发混合负载用「按请求内容自动分流」避免共享可变
     脚本的竞态；
   - 请求全量录制（头+体）——用于断言「转发体被钳制/字段被注入/不该发起的调用
     没有发生」；
   - 凭证用已知测试密钥加密落库（鉴权不对则 401——顺带成为泄漏扫描的明文靶）。
3. **全真装配入口**
   - 用与生产同款的「装配根 + 配置装载」启动被测系统（真数据库、真缓存、真后台
     机制），仅网络对端指向替身；
   - 环境开关走系统自己的配置校验（如 SSRF 逃生门类开关仅在非生产条件可用），
     不要绕过配置层注入；
   - 真实 HTTP 端口起服务（port 0 自动分配），测试用真 fetch 打网络栈；
   - 同一世界可挂多个不同配置的实例（如两种预扣策略形态）。
4. **台账与对账 helper**
   - 发凭证/建账号/充值（走真实资金动词，不直插复式账表）；
   - 驱动后台结算：定向认领 → 处理 → 轮询直到无待结算行（带终态超时）；
   - 强对账断言：余额 == 注入 − Σ实扣明细、在途/未决 == 0、流水链连续、
     投影列 == 明细合计。
5. **共享状态复位**：熔断/限流类键住在共享缓存时，提供按前缀扫描清理的 helper，
   文件级串行 + 用例前显式复位双保险。

## 旧 e2e 迁移对照法

0. **先体检再迁**：旧 e2e 本身可能是坏的——flaky、用例间共享状态耦合、断言与
   旧实现实际行为矛盾。矛盾处按「旧实现行为 vs 旧断言」做裁决并记录（哪边是
   真 bug 就修哪边），不许硬改断言凑绿；flaky 用例先在旧仓复现定性再迁。
   **迁移顺序**：资金/数据丢失旅程 > 核心业务链路 > 长尾（与审计优先级同源）。
1. **逐条等价**：旧断言（状态码、账单数、对账公式、表间一致性）原样保留；
2. **种子事实显式化**：旧测试依赖的共享环境事实（价格表、目录名、参数）变成
   kit 的种子数据，值与旧断言一致——**断言值零漂移**；旧硬编码 id 改为断言
   世界返回的种子 id；
3. **装置适配逐条记录**（写进迁移文档，禁止静默改断言）：
   - 线名/协议归一（新旧版本的请求字段名差异）；
   - 旋钮语义映射（旧「建连超时」在新架构的等价预算项；紧/宽两分支都要测）；
   - 内部机制变化引发的形态调整（如流式从主动泵送变按需拉取时，「拉满再掐」
     攻击向量改为读完全部帧再断，计量口径仍与交付一致）；
4. **真上游契约单列**：需要真实凭证/花钱的场景独立成 real 门（文件名约定 +
   默认门禁排除 + 显式环境开关 opt-in + 凭据从现有环境克隆重加密，不复制共享行）；
5. **跨应用依赖挂账**：依赖尚不存在的外部应用（如后台 worker）的用例显式挂账，
   不造假替身冒充通过。

差分对照（同一请求打新旧两套比对输出）不作为主证明路径——等价性的证明力来自
「断言逐条等价 + 差异全部点名」，双跑对照无法覆盖时序/副作用面；只可作为核心
旅程的补充抽样信号，且结论仍以断言口径裁决。

## 双形态进程冒烟

- 源码运行形态（开发态解释器）与构建产物形态（生产启动命令）各起一个真实子进程；
- 验证点：健康探针全 200、鉴权放行/拒绝各一、一次全链业务请求成功、优雅停机
  信号后正常退出码；
- 进程环境注意：模块解析条件（development/production）可能改变依赖目标，
  产物形态需要先构建；日志美化器等开发依赖在子进程里可能解析不到，需要补齐；
- 数据自清 = 世界销毁；冒烟断言结算对账（不只是 200）。

## 运行装置

- 根级脚本三个入口：默认门（hermetic，进日常验证）/ real 门（opt-in）/ 冒烟单入口；
- e2e 目录不是包时的依赖解析：符号链接到依赖闭包最全的最近包的 node_modules，
  测试执行器也从该包目录启动、配置文件指回 e2e 目录——README 写明这个机制；
- 文件级串行（共享缓存键 + 隔离区渠道 id 可能撞名）；超时给足（全真装配 + 真网络）。
